# 📊 Retail Sales Performance Dashboard

## 📌 Project Overview

The Retail Sales Performance Dashboard is a data analytics project developed
to analyze retail sales data and generate meaningful business insights.

The project transforms raw retail transaction data into an interactive
dashboard that helps understand sales performance, profitability, customer
segments, product performance, and regional trends.

---

## 🎯 Problem Statement

Retail businesses generate large amounts of sales data, but raw data can be
difficult to interpret and use for decision-making.

This project aims to clean, analyze, and visualize retail sales data to
identify important business trends and provide actionable insights through
an interactive Power BI dashboard.

---

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify high-performing products and categories
- Analyze sales across different regions and customer segments
- Understand sales trends over time
- Identify profitable and underperforming areas
- Build an interactive and visually appealing dashboard
- Support data-driven business decision-making

---

## 🛠️ Tools & Technologies

- **SQL / MySQL** – Data querying and analysis
- **Microsoft Excel** – Data cleaning and preliminary analysis
- **Power BI** – Data visualization and interactive dashboard
- **CSV** – Dataset format

---

## 📂 Dataset

The project uses the Superstore retail sales dataset.

The dataset contains information related to:

- Orders
- Customers
- Products
- Categories
- Sales
- Profit
- Quantity
- Regions
- Customer Segments
- Order Dates

Both the original and cleaned datasets are included in the `Dataset`
folder.

---

## 📈 Key Performance Indicators

The dashboard includes the following KPIs:

- **Total Sales**
- **Total Profit**
- **Total Orders**
- **Total Quantity**
- **Average Order Value**

---

## 📊 Dashboard Features

The Power BI dashboard includes:

- 📈 Sales Trend Over Time
- 📊 Sales by Category
- 📊 Profit by Category
- 🌍 Profit by State
- 🍩 Sales Distribution by Region
- 📊 Sales by Segment
- 🏆 Top 10 Products by Sales
- 🔎 Interactive filters

---

## 💡 Key Insights

The dashboard helps identify:

- Categories generating the highest sales
- Regions contributing significantly to sales and profit
- Customer segments with higher sales contribution
- Products with the highest sales
- Changes in sales performance over time
- Differences between sales and profitability
